# Star Customs Website

## Before publishing
1. Replace every `https://discord.com/` placeholder with your actual Star Customs Discord invite.
2. Open `payment.html` and replace `https://buy.stripe.com/REPLACE_ME` with your Stripe Payment Link.
3. Upload the files to your web host.

The payment page intentionally uses a Stripe Payment Link, so this static website does not need to store card information or contain a Stripe secret key.
